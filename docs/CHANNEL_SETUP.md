## 5. 作成の手順（ユーザー）

1. **ブランドアカウントで、チャンネルを作る**（個人名を出さない運用のため。Googleアカウントの設定で、「ブランドアカウント」を選ぶ）。
2. 名前を「寄り道ラボ」にする。ハンドルを決める（上の候補）。
3. プロフィール画像・バナーをアップロードする。説明文を貼る。
4. **電話番号の認証**（YouTube Studio → 設定 → チャンネル → 機能の利用資格）。**15分を超える動画（本能寺は30分）の投稿と、カスタムサムネイルに必要**。
5. 既定のアップロード設定：カテゴリ＝教育、言語＝日本語、ライセンス＝標準のYouTubeライセンス、コメント＝許可（不適切な可能性があるものは保留）。
6. 再生リストを作る（空でよい）：「地図・地理」「歴史」「科学・言葉」。
7. 「改変または合成されたコンテンツ」の設問の方針：合成音声（VOICEVOX）を使う動画は、設問を読んで判断する。生成画像を使う動画は、その旨を申告する。
8. 収益化は、条件（登録者数・総再生時間など）を、**YouTube の最新のヘルプで確認**する。
