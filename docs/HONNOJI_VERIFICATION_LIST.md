作成：2026-10-15。**動画の記述の根拠は、日本語版Wikipedia(と、一部、検索結果)までです。原著・一次史料は、未確認です。** 特に、**研究者名を伴う学説の紹介**は、誤りがあると、本人・読者からの指摘や削除要請につながり得ます(ChatGPTの評価も「公開前の史実確認：BLOCKER」)。このリストは、「どの文が、誰の、どの著作に依存しているか」と、「確認できなかった場合の弱めた表現」をまとめたものです。

**使い方**：優先度が高い順に、原著(図書館・書店・電子書籍・論文データベース)で該当箇所を確認し、★欄に「一致／部分一致／不一致」と、ページ・確認日・確認者を書く。**不一致または確認できない場合は、「確認できない場合の対処」を適用**し、台本(`scripts/hn_story.py`)・画面(`data/hn_scene_visuals.json`)・字幕を直して、音声・映像を作り直す。

- 「書名」欄：**Wikipediaの記事の注・参考文献で確認できたもの**は「(Wikipedia注)」、**ChatGPTの評価が挙げたが、私が未確認のもの**は「(ChatGPT提示・未確認)」、特定できないものは「要特定」。
- 優先度：A＝研究者名と学説の対応そのもの、B＝評価・立場の表現、C＝補足の事実。

## 4. 確認の進め方(提案)

1. **まず1〜16(研究者名つき)を、図書館で確認する。** 同じ研究者の著書は、1冊で複数の項目が確認できる(高柳『明智光秀』で1・3・4、小和田で6・14、立花で7・15、鈴木・藤本で5)。
2. 手元で確認できない(絶版・入手困難)ものは、**「確認できない場合の対処」を適用**する(人名を外すのが、最も安全)。
3. 確認結果を、★欄に書き、`out/script_crosscheck_log.md` に追記。台本を直したら、**読みの確認(`hn_kana_check.py`)→音声→合成**を、やり直す(手順書 `HONNOJI_PRODUCTION_PLAYBOOK.md`)。
4. すべてを確認する前に、**最低限、1〜16のうち「人名を外す」で済むものは外す**ことでも、BLOCKERの主な原因(研究者名つきの断定)は、大きく減る。
